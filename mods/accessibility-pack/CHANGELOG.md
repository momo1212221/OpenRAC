# Changelog

## 0.2.0

- Added Enhanced RAC Style health panel.
- Added eight-cell health strip.
- Added stylised low-health and lethal-protection banners.
- Replaced plain HUD text with the OpenRAC 1.14 overlay renderer.

- Initial submission-ready release.
- Deterministic normal-hit reduction and optional invulnerability.
- Lethal-hit protection with cooldown.
- Large health HUD and low-health warning.
- PAL and NTSC-U support.
