# Custom Skin Studio

An installable OpenRAC tool mod for creating Ratchet texture skins.

## Install

In OpenRAC, open **Mods -> My mods -> Add a mod** and use:

`https://github.com/momo1212221/OpenRAC/tree/feat/custom-skins`

If GitHub's API is temporarily unavailable, download `custom-skins-0.1.0.zip` from the
`custom-skins-v0.1.0` release and add it with **File...** instead.

## Use

Open **Custom Skin Studio**, load Ratchet's class-0 skin from the prepared levels,
edit or replace its PNG textures, then choose **Build mod ZIP**. Add the generated
ZIP with **Mods -> My mods -> File...**.

The source export contains assets from the user's own prepared game data and is
not intended for redistribution.
